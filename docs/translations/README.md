# WordPress.org listing translations

These PO catalogues cover the plugin-directory description, FAQ, installation steps, changelog and screenshot captions. Each of the five locales contains all 60 strings in the current marketing readme. They are AI-assisted and require review by the relevant WordPress.org locale team.

Interface translations live separately in `languages/` and are bundled with the plugin. Files under `docs/` are excluded from both release builders.

Import the appropriate PO into the plugin's Stable Readme project on translate.wordpress.org after its source strings refresh. Imports from the author account have **Waiting** status; only a locale translation editor can approve the public listing translation. Development Readme can also be populated once its updated source strings are available.
